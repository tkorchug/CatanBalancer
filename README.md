# Balanced CATAN board generator

`main.py --version original`

`--version` arg is required, it should be either `original` or `got`.

### Rules:

1) For classic version only: no 2 brick tiles or stone tiles are next to each other
2) No 3 sheep, wood or weed together
3) No resource tile is too close to its port
4) Not the same numbers are next to each other
5) No 6 or 8 are next to each other
6) No same number on the same resource
7) No 6 or 8 on the same resources
8) For GOT version only: no 6th and 8th on bottom line
